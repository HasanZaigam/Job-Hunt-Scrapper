# Deploy your own dashboard on Render (free)

The dashboard is where you click **Generate docs** and **Mark applied**. It needs
its own host. The scraper, matcher and LinkedIn drafts run on GitHub Actions and
need no server.

Important: any dashboard URL you find in old notes belongs to the upstream
project, not you. Your deploy is separate and uses YOUR Supabase.

## 0. Before you start
- Your Supabase project has the schema: run `database/schema.sql`, then every
  file in `database/migrations/` in order (001 to 005), in the Supabase SQL editor.
- You have: Supabase URL + service_role key, a Gemini API key, and a GitHub repo
  with this code on `main`.

## 1. Create the service
1. render.com -> sign in with GitHub.
2. **New -> Blueprint** -> select this repo (it reads `render.yaml`).
3. Fill the values Render asks for:

| Variable | Value |
| --- | --- |
| `SUPABASE_URL` | https://YOUR-REF.supabase.co |
| `NEXT_PUBLIC_SUPABASE_URL` | same as above |
| `SUPABASE_SERVICE_KEY` | service_role key (not the anon key) |
| `GOOGLE_API_KEY` | Gemini key |
| `DASHBOARD_EMAIL` | the email you will log in with |
| `DASHBOARD_PASSWORD` | a new password you choose (not one you use elsewhere) |
| `AUTH_TOKEN` | generated by Render, leave it |

4. **Apply**. The first Docker build takes several minutes (it installs Chromium for PDFs).
5. Open the `https://....onrender.com` URL Render gives you and log in.

## 2. Auto-deploy on merge
Render service -> Settings -> **Deploy Hook** -> copy the URL -> in GitHub add it as
repo secret `RENDER_DEPLOY_HOOK`. After that `.github/workflows/render-deploy.yml`
redeploys the dashboard whenever dashboard files change on `main`.

## 3. Free plan behaviour
The service sleeps when idle; the first request after a break takes 30-60 seconds.
That is normal.

## 4. If something fails
- Login says invalid: the email/password must match `DASHBOARD_EMAIL` / `DASHBOARD_PASSWORD` on YOUR Render service.
- Pages show empty or error: check `SUPABASE_URL`, the service_role key, and that the migrations ran.
- "Generate docs" fails: check `GOOGLE_API_KEY` and the Render service logs.
